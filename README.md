## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/ZenNook.git`
2. `cd ZenNook`
3. Install in editable mode: `pip install -e .`

## Configuration

ZenNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
